# ARTISTO

### PSE VU Project

## Project Description and Goals

**ARTISTO** is an online marketplace designed to connect artists and buyers in one accessible platform.

Our goal is to make it easy for **buyers to discover and purchase artwork that matches their preferences**, while giving **artists a place to showcase their work, reach potential customers, receive commissions, and create new sources of income**.

The platform aims to simplify the process of discovering, buying, selling, and commissioning creative work while building a community around art and creativity.

## MVP Roadmap

### 1. Alpha — Core MVP

- Basic creator profiles
- Create and manage product listings
- Marketplace / Discover + basic search
- Product pages
- Buy Now

### 2. Beta — Expanded MVP

Everything from Alpha, plus:

- Registration & login
- Likes, Favorites & Follow
- Search filters and categories
- Make an Offer
- Reviews & ratings
- Notifications
- Basic reputation statistics
- Buyer/Seller chat

### 3. Final Product

Everything from Beta, plus:

- Creator ranks: **New → Rising → Trusted**
- Verified transactions
- Improved ordering
- Reporting / dispute system
- Improved admin tools
- Polished responsive UI/UX

## Tech Stack

**Backend:** C# / ASP.NET Core
**Frontend:** React
